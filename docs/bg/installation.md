# Инсталация

Творец корици се управлява с [uv](https://docs.astral.sh/uv/). Не е
нужно да управлявате виртуална среда сами — `uv` прави това вместо вас.

## Изисквания

- Инсталиран [uv](https://docs.astral.sh/uv/getting-started/installation/)
  (работи по еднакъв начин на Windows, macOS и Linux).
- Python 3.11+ (uv автоматично изтегля подходящ интерпретатор, ако няма
  такъв инсталиран).

## Инсталиране и стартиране

От главната директория на проекта:

```bash
uv sync
uv run tvorec-cover
```

Това инсталира основните зависимости (PySide6, Pillow) и стартира
графичния интерфейс.

## Незадължително: ИИ уголемяване на изображения

Ако изходните изображения са по-малки от крайния размер за печат,
приложението може да ги уголеми чрез модел за изкуствен интелект за
свръхрезолюция (FSRCNN) през OpenCV, вместо стандартно преоразмеряване. Това
е незадължителна добавка, защото OpenCV е сравнително голяма зависимост:

```bash
uv sync --extra upscale
```

Ако тази добавка не е инсталирана (или липсва файлът на модела),
приложението автоматично преминава към стандартно преоразмеряване (Lanczos)
— приложението продължава да работи, само с по-ниско качество при
изображения с недостатъчна резолюция.

За да използвате ИИ уголемяването, изтеглете файл с модел FSRCNN (напр.
`FSRCNN_x4.pb`) и посочете пътя до него в приложението; вижте
[`src/cover_generator/resources/models/README.md`](../../src/cover_generator/resources/models/README.md)
за повече информация къде да го поставите.

## Изпълнение на тестовете

```bash
uv run pytest
```

## Използване на приложението без инсталация

Не е нужно Творец корици да се стартира от изходния код. Самостоятелни,
готови за стартиране изпълними файлове за Windows, macOS и Linux се
изграждат автоматично при всяко маркирано издание и се прикачват към
страницата с издания (Releases) на проекта в GitHub — не са нужни Python
или `uv`.

## Изграждане на самостоятелен изпълним файл сами

```bash
uv run pyinstaller packaging/tvorec-cover.spec --noconfirm
```

Вижте уменито (skill) `build-release` в `.claude/skills/` за пълния процес с
PyInstaller (PyInstaller не компилира кръстосано, така че това трябва да се
изпълни поотделно на всяка целева операционна система).
